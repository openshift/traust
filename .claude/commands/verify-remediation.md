---
description: "Check patched code against prior audit findings and report resolution evidence and regressions."
---

Verify that security findings from a previous audit have been resolved in a patched version of the repository. Load the skill at .claude/skills/verify-remediation/SKILL.md and follow its full procedure — $ARGUMENTS should include the path to the original audit report and either a GitHub/GitLab URL (with optional @branch or @commit), a local repo path, a GitHub PR or GitLab MR reference (the unmerged head is checked out — merging is not required), or the keyword "latest" for the patched code. The skill ingests each original finding, checks the patched code at every finding location using the same OWASP ASVS, OWASP K8s Top 10, CIS, DISA STIG, SLSA, OpenSSF Scorecard, and PEACH framework criteria as the original secure-code-audit, assigns a verdict (resolved, partially_resolved, unresolved, new_approach, regression, false_positive, risk_accepted) with evidence and commit-level attribution, checks the diff for regressions, and produces a verification report validated against contracts/schemas/verification.schema.json.
