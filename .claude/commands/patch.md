description: "Generate independently reviewed candidate patches for confirmed findings as unapplied diffs."
---

Generate candidate security fixes for the findings at $ARGUMENTS using the patch skill. Load the skill at .claude/skills/patch/SKILL.md and follow its full procedure — ingest TRIAGE.json (canonical) / a `<repo>-security-audit.json` report / `*-vuln-findings.json` / `*-pqc-facts.json` (actionable first-party PQC blockers) / an external vuln-pipeline results directory, then per confirmed finding spawn a patch subagent plus an independent reviewer, writing inert diffs to `./PATCHES/bug_NN/{patch.diff,patch_result.json}` and roll-ups PATCHES.md + PATCHES.json. The skill NEVER applies a diff to the target repo and the Write scope is confined to `./PATCHES/` and `./.patch-state/`. `$ARGUMENTS` is a findings path plus optional flags: `--repo PATH` (read-only target clone), `--top N`, `--id fNNN`, `--model M` (execution-verified vuln-pipeline delegate only), `--fresh`. State checkpoints to `./.patch-state/` and resumes on re-invocation.
